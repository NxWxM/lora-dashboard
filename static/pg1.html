LoRa-based Safety System for Underground Miners

This project is designed to enhance the safety of underground miners by continuously monitoring environmental parameters such as gas levels, temperature, and humidity using **LoRa (Long Range)** technology. The system provides real-time data to ensure **early detection of hazardous conditions** and quick response in case of emergencies, bringing next-generation safety to mining operations.
